# Third-party notices

Video Downloader is made by Tanvir. It runs on these free, open-source projects.

| Project | What it does in the app | License | How it gets to your computer |
|---|---|---|---|
| [uv](https://github.com/astral-sh/uv) by Astral | Sets up Python and the other tools on first launch | MIT or Apache-2.0 | Included in the download (`bin/uv`) |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Downloads videos and music | Unlicense (public domain) | Installed from PyPI on first launch |
| [gallery-dl](https://github.com/mikf/gallery-dl) | Downloads photos and photo posts | GPL-2.0 | Installed from PyPI on first launch |
| [FFmpeg](https://ffmpeg.org) via [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) | Joins, converts and tags media files | LGPL / GPL (FFmpeg), BSD-2-Clause (imageio-ffmpeg) | Installed from PyPI on first launch |
| [Deno](https://github.com/denoland/deno) | Lets yt-dlp handle YouTube's player | MIT | Installed from PyPI on first launch |
| [pywebview](https://github.com/r0x0r/pywebview) | Shows the app in its own window on Mac | BSD-3-Clause | Installed from PyPI on first launch (Mac only) |
| [Python](https://www.python.org) | Runs the app | PSF License | Downloaded by uv on first launch |
| [Mona Sans](https://github.com/github/mona-sans) by GitHub | The app's typeface | SIL Open Font License 1.1 | Embedded in the app's interface |

Only uv is redistributed in the download. Its license texts are in the `licenses` folder of each download.
